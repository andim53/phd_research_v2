# paper_amorphous

Scientific paper project: **Amorphous Pt(P) from GOFEE/AGOX global optimization, with spin Hall conductivity (SHC) from FLAPW** (Andi Muhammad Nur Fitrah Syamsul, Kohji Nakamura — Mie University).

This project initializes the `scientific-paper-writing` workflow on the amorphous Pt(P) system: P interstitials in an fcc Pt 3×3×3 host, generated by the GOFEE/AGOX GPR+LCB search, with the next goal of computing the spin Hall conductivity via FLAPW.

## What's here
- `papers/paper1/` — main manuscript (RevTeX 4.2) split into `sections/`, plus `supplementary/` (SPIE-class SI). Both compile with tectonic.
- `codes/` — figure/analysis code (to be written).
- `analysis/` — regenerated figures + result JSONs (to be produced).
- `data/` — raw AGOX/GPAW results (read-only reference): `17_PPt` (Pt–P), `11_bTa`, `16_bW`.
- `tmp/` — FLAPW 4.58 + ELPA install, and the SHC example (`SHC Calculation/HEA_SHC_Auto_Python_FLAPW/`).

## Systems & scope
- **Focus:** Pt(P) — P interstitials in fcc Pt 3×3×3 host, 20% and 30% P (amorphous), across supercell families `0_plus5cell` (+5%), `1_plus0cell` (+0%), `2_plus3cell` (+3%). The `3_plus10cell` (+10%) family is **excluded**.
- **Reference:** 0% and 10% P leaves.
- **Supplementary discussion:** `11_bTa` (B in Ta) and `16_bW` (B in W) systems.

## Build
```bash
cd papers/paper1 && ~/.local/bin/tectonic main.tex          # main manuscript
cd papers/paper1/supplementary && ~/.local/bin/tectonic article.tex   # SI
```
