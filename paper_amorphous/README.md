# paper_amorphous

Scientific paper project: **Amorphous Pt(P) from GOFEE/AGOX global optimization, with spin Hall conductivity (SHC) from FLAPW** (Andi Muhammad Nur Fitrah Syamsul, Kohji Nakamura — Mie University).

This project runs the `scientific-paper-writing` workflow on the amorphous Pt(P) system: P interstitials in an fcc Pt 3×3×3 host, generated by the GOFEE/AGOX GPR+LCB search, with the next goal of computing the spin Hall conductivity via FLAPW.

### Data model (Pt–P, `data/17_PPt/`)
- **Host:** fcc Pt, a = 3.975534 Å, 3×3×3 supercell (Pt₁₀₈). P interstitials added via `generate_interstitial_alloy.py`; count `B = (C·A)/(1−C)`.
- **Cell families** (from `alloy_structure.xsf` PRIMVEC): `0_plus5cell` 12.523 Å (+5%), `1_plus0cell` 11.927 Å (+0%), `2_plus3cell` 12.284 Å (+3%), `3_plus10cell` 13.119 Å (+10%, **excluded**). Note: `main.py` `SCALE_CELL=1.05` is stale for the +0/+3 families — trust the xsf cells.
- **Compositions:** 3×3×3 leaves = Pt₁₀₈ + P interstitials (20P = Pt₁₀₈P₂₇, 30P = Pt₁₀₈P₄₆); `0_PPt_4x4_20P` = Pt₂₅₆P₆₄ (n=320).
- **AGOX pipeline:** `RattleGenerator` + `AmorphStructRandomize` + `AmorphPermutationGenerator`; GPR (RBF kernel, Repulsive prior) + LowerConfidenceBoundAcquisitor; GPAW LCAO/dzp/PBE, kpts (1,1,1); `LocalOptimizationEvaluator`; per-seed `1_db/db_*.db`.
- **Analysis:** `run_analysis_indices.py` per leaf (from `_run/0_lcb/2_analysist`), `iteration >= 10` filter, `--e-max 0.5` for Pt–P. XRD crystallinity via `xrd_simulate_crystallinity.py` (see `data/17_PPt/DISCUSSION.md`).

## 3. Tutorial (reproduction)

How to reproduce the paper build and figure regeneration.

### Prerequisites
- **Python env:** `agox_v2` (`/home/think/miniconda3/envs/agox_v2/bin/python`) — AGOX, ASE, scipy, matplotlib.
- **FLAPW/SHC env:** `flapw_2` conda env (HPC, pjsub).
- **LaTeX:** tectonic 0.17.0 at `~/.local/bin/tectonic` (no system TeX).

### 1. Compile the main manuscript
```bash
cd papers/paper1
~/.local/bin/tectonic main.tex        # → main.pdf
```
`main.tex` `\input`s `sections/01_abstract … 06_ack_dataavail.tex` in order. Figures live in `figures/`.

### 2. Compile the Supplementary
```bash
cd papers/paper1/supplementary
~/.local/bin/tectonic article.tex     # → article.pdf
```
Uses `spieman.cls` + `spiejour.bst` + `report.bib`; figures in `figures/`.

### 3. Regenerate figures (emit → plot)
All figure scripts live in `codes/` and run under the `agox_v2` env python. **Two-step pattern:** first emit the datasets (CSV + per-figure JSON) you and the owner can inspect, then plot from them. *(Scripts to be written — see `paper_status.md`.)*

```bash
cd codes
# Step 1 — emit datasets (CSV + JSON) into analysis/
/home/think/miniconda3/envs/agox_v2/bin/python emit_datasets.py
# Step 2 — plot from the emitted datasets
/home/think/miniconda3/envs/agox_v2/bin/python draw_*.py
```

### Figure conventions (match `_analysist`)
- **rcParams:** serif font 12, ticks-in on all sides, no grid, dpi 300, `figure.autolayout=True`.
- **Energy axis:** `$E_{i}-E_{glob}$ (eV/atom)`, per-atom, global min = 0.
- **Minimum-ensemble filter:** keep only AGOX `iteration >= 10` (Phase II onward).
- **XRD crystallinity:** peak-fraction CI + integrated CI (see `data/17_PPt/DISCUSSION.md`).
