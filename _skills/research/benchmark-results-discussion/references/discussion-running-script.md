# DISCUSSION.md must include the actual running script (user requirement)

The user requires that **every DISCUSSION.md state the exact producing command** —
the full `python <script>.py` line with all flags and `--output` — in a dedicated
`## Running script` section, so the discussion is reproducible and traceable to its
generating invocation. (Prompted by project `b_nestedsampling`, PROMPTS flag
`20260827_0059`.)

## How to apply

- Put `## Running script` near the top, just before the setup table ("What was run").
- State the command run **from the project root**, e.g.:
  ```
  /home/think/miniconda3/envs/agox_v2/bin/python gpr_accuracy.py --cv --cv-folds 3 \
      --fez --uncertainty --bin-width 0.1 --output ./_tmp/gpr_acc_fez_cv3_out
  ```
- Apply to **every** DISCUSSION.md, including ones auto-generated by a script. For a
  tool that emits DISCUSSION.md itself (an analysis script with a
  `_write_*_discussion` helper), bake the command into the writer so it is always
  included.
- The file can sit beside gitignored results (e.g. under `_tmp/`) — it need not be
  git-tracked; just keep it with the run it documents.

## Example placement

```
