# GPR Prediction Failures on Perturbed Structures

## Symptom

`gpr.predict_energy(atoms)` returns unphysical energies (10^20 to 10^38 eV)
when called on structures generated by perturbing training-set structures.

## Root Cause

The GPR model trained on 100 structures from the AGOX database uses a
Fingerprint descriptor with 720 features. The training set occupies a
compact region in feature space (features range 0–5.1, mean 0.16).

When positions are perturbed:
1. The fingerprint feature vector moves far from the training manifold
2. The RBF kernel values become extremely small (K → 0 for distant points)
3. The GPR prediction `K @ alpha` can diverge because alpha has both
   positive and negative components summing to approximately zero
4. Small numerical differences in K get amplified by the large alpha values
   (alpha ranges -17.8 to +19.3)

## Investigation Log

### Test 1: Same structure, repeated predictions
```python
base = traj[0].copy()
for _ in range(5):
    E = gpr.predict_energy(base)
    # All return -392.3206 eV — stable
```
✓ Repeated predictions on the same copy are stable.

### Test 2: Creating new Atoms vs in-place modification
```python
# New Atoms from scratch — UNPHYSICAL
new = Atoms(symbols=base.symbols, positions=new_pos, ...)
gpr.predict_energy(new)  # ~10^21 eV

# In-place modification on copy — PHYSICAL
base_copy = traj[0].copy()
base_copy.positions += noise
gpr.predict_energy(base_copy)  # ~-392 eV
```

### Test 3: Which training indices fail?
Applied the SAME fixed noise vector to ALL 100 training structures.
Result: 0/100 predictions physical, 100/100 garbage.
→ The issue is NOT specific training indices — it's the new Atoms creation.

### Test 4: Feature distance analysis
Training features: min=0, max=5.1159, mean=0.1566, 720 dimensions.
Inter-structure L2 distances: 1.3–6.7.

Perturbation feature distances (from traj[0]):
- amp=0.0001A: L2=0.0002 (safe)
- amp=0.001A: L2=0.002 (safe)
- amp=0.01A: L2=0.026 (safe)
- amp=0.2A: L2=66 (FAR outside training)

### Test 5: Manual kernel computation
Training feature X_train (100×720), test feature x_test (720,).
L2 distances: min=0.026, max=6.7, mean=5.1.
Kernel values: min=0.618, max=5.53, mean=1.10.
Alpha: min=-17.8, max=19.3.

Manual prediction: `K @ alpha = 0.087 eV` (relative to mean).
GPR prediction: `-392.31 eV` (= mean_energy + relative prediction).

This confirms the GPR is working correctly on structures that stay in the
training manifold. The issue is obtaining a valid feature vector from the
perturbed atoms.

## Solution

1. **Never create new Atoms** via `Atoms(symbols=..., positions=...)`.
   Use `base.copy()` and modify `positions` in-place.

2. **Keep perturbation amplitude ≤ 0.01A.** Larger perturbations move
   fingerprint features outside the training manifold.

3. **For nested sampling, use `perturb=0`.** Sample structures directly
   from the DB without modification. This guarantees the fingerprint
   features stay within the training distribution.

4. **For confinement clipping, only clip out-of-bounds atoms.** Using
   `np.clip()` on all atoms corrupts structures by moving atoms that are
   already inside the confinement box.
