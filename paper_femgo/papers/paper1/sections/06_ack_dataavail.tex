\section*{Data Availability}
The minimum-ensemble dataset containing the atomistic coordinates and total potential energies of all 1,207 spin-polarized DFT-evaluated configurations is not publicly available but is available from the authors upon reasonable request.

The source code detailing our modified AGOX and GOFEE active learning framework—including the custom dual-scale generator controls—is publicly available on GitHub at \url{https://github.com/andim53/Minimum-ensemble}.
