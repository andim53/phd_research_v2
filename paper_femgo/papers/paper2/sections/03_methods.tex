\subsection{Algorithm of Minimum-Ensemble Sampling}

To construct a biased exploration strategy within an active learning framework to sample a minimum-ensemble of surrogate-relaxed structures dominated by local minima, as shown in Fig. \ref{Fig_flow}, we incorporate the Global Optimization with First-principles Energy Expressions (GOFEE) framework \cite{bisbo2022}, implemented within the Atomic Global Optimization X (AGOX) package \cite{Christiansen2022}, which utilizes Gaussian Process Regression (GPR) to construct a surrogate PES on-the-fly (see the details in the Supplemental Materials, Secs. I-III). This framework is ideal for generating this ensemble, as the algorithm uses the Lower Confidence Bound (LCB) acquisition function, defined as $a_{LCB}(\mathbf{x}) = \mu(\mathbf{x}) - \kappa \sigma(\mathbf{x})$, to identify relevant configurations. This equation balances the sampling of low-energy states, $\mu(\mathbf{x})$, with high-uncertainty regions, $\sigma(\mathbf{x})$, where the trade-off is controlled by $\kappa$. In this way, the sampling process simultaneously targets low-energy configurations and explores regions outside of the existing GPR database, i.e., generating a minimum ensemble of local minima. Furthermore, each structure is relaxed with GPR prior to storage, which filters out transient trajectory states. 

\subsection{Two Stochastic Rattling Generators}

To minimize the sampling of unphysical states and target local minima, we implement a biased exploration strategy featuring a candidate generator and an iteration control mechanism (dashed box in Fig. \ref{Fig_flow}). This approach employs two stochastic rattling generators—small-scale and large-scale—to produce 20 candidates per iteration across 100 iterations, partitioned into three distinct phases. Phase I (iterations 0–9) relies exclusively on the small-scale generator; unlike the random initial structures used in Refs. \cite{Paleico2020, bisbo2022}, this phase initializes iterations by applying a 1.5 Å maximum displacement to a reference configuration consisting of an $\text{Fe(001)}$ monolayer on a flat $\text{MgO(001)}$ monolayer substrate. This reference configuration is a $5\times5$ supercell containing 25 atoms per species, with the substrate remaining fixed during Fe layer optimization. Phase II (iterations 10–24) combines the small-scale ($N = 10$) and large-scale ($N = 10$) generators, where the latter bypasses the reference configuration by extracting base structures from the database of previous iterations and applying a 2.5 Å maximum displacement to half of the Fe atoms. Finally, Phase III (iterations 25–100) employs the large-scale generator exclusively ($N = 20$) to focus the search on widespread exploration.

\subsection{Minimum-Ensemble}

Following candidate generation, GPR optimization is applied exclusively during Phase II and Phase III to evaluate the generated configurations. Across all three phases, the $N = 20$ candidates undergo filtering via an LCB acquisition function—controlled by $\kappa = 2$ to balance the sampling of regions outside the GPR database and low-energy configurations—to select a subset of $M$ candidates for DFT evaluation. The $M$ evaluated candidates collected from each iteration are compiled to construct the final minimum-ensemble. However, structures generated during Phase I are excluded from this ensemble. These initial configurations serve solely to populate the initial database used for GPR optimization and do not undergo local relaxations, meaning they do not accurately represent local minima on the PES.

To characterize the degeneracy of this ensemble, we estimate the state density $g(E)$ via Kernel Density Estimation (KDE) with a Gaussian kernel, using a smoothing bandwidth $h$ set by Scott's rule, $h = M^{-1/5} \sigma$, where $M$ is the number of configurations and $\sigma$ the sample standard deviation of the per-atom relative energies (see Sec. III).
