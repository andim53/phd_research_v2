# 0_pdos — Projected Density of States (PDOS) for Fe/MgO and FeB/MgO

## What this project does

Computes and analyses the **projected density of states (PDOS)** for Fe/MgO
hetero-epitaxial systems and their boron-doped (FeB/MgO) variants, using the
GPAW DFT code (LCAO mode) on top of structures generated by AGOX global
optimisation.

The PDOS is the central observable: it reveals how the Fe-3d, O-2p and B-2p
orbitals contribute to the electronic structure near the Fermi level, and lets
us compare different growth morphologies (e.g. "Island" vs "Flat" Fe films on
MgO) and the effect of B doping.

## Key systems

- **Fe/MgO** — Fe film on a MgO(001) substrate. Reference DOS/PDOS in
  `_results/10_dos` and `_results/37_dos`. Comparison between an "Island"
  (seed 3) and "Flat" (seed 4) growth mode.
- **FeB/MgO** — same substrate with 3 boron adatoms (Fe25 Mg25 O25 B3, 78
  atoms). Structures from the `dataset_boron3` AGOX search. The global ground
  state (seed 4, db index 86, E = −455.41 eV) is the target of run
  `_runs/1_pdos_boron3_gs`.

- Heavy HPC DOS/PDOS runs: `gpaw_env` via PJM batch, launched with
  `pjsub job_dos.sh` (24 cores).

## Key decisions & tradeoffs

| Decision | Choice | Why |
|---|---|---|
| DFT code / mode | GPAW LCAO, basis=dzp, xc=PBE, spinpol | matches reference `10_dos`; good for PDOS |
| k-points | (12,12,1) | dense in-plane sampling of the slab |
| DOS grid | emin/emax = −15/10 eV, npts=2000, width=0.15 | Fermi-shifted window |
| PDOS projection | per-element summed (Fe-d l=2; O-p, B-p l=1; m=None) | matches `37_dos` layout |
| Ground state source | global min across all 7 `dataset_boron3` seeds | "only the ground state" |
